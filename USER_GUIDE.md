# User Guide — Berget Law Entity Manager

This guide is for Berget Law attorneys and staff using the Entity Manager
day to day. **Status: Phase 0.** The app currently has only placeholder
pages; this guide will be filled in section by section as each module
ships, and a full guide will exist by Phase 15.

## What this app is for

One place to track every entity Berget Law serves as registered agent for:
who the client is, whether the entity is active, when its annual report or
other compliance task is due, whether it's been billed and paid, and where
the related documents and notes live. It replaces spreadsheets and
shared-drive folders for this purpose.

## Navigation

The sidebar (or the menu icon on a phone) has 11 sections:

| Section | What it's for |
| --- | --- |
| Dashboard | Today's priorities: overdue items, due-today items, upcoming deadlines |
| Entities | Every business entity the firm tracks |
| Clients | Every client the firm represents for registered agent purposes |
| Annual Reports | This year's (or any year's) annual report compliance campaign |
| Tasks / Ticklers | Your to-do list and the firm's shared work queue |
| Billing | Registered agent fee invoices and payment status |
| Documents | Filings, confirmations, and correspondence |
| Calendar | Deadlines and reminders, with optional Google Calendar sync |
| Reports | Exportable lists for compliance and management purposes |
| State Rules | Due-date and fee rules per state and entity type (Montana first) |
| Settings | Firm defaults, fee settings, users, integrations |

## Color meaning (used throughout the app)

| Color | Meaning |
| --- | --- |
| Green | Active / current |
| Yellow | Due soon |
| Orange | Waiting on client |
| Red | Late / delinquent |
| Gray | Archived / inactive |
| Blue | Ready to file |
| Purple | Needs review |
